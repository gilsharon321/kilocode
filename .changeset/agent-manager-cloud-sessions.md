Show existing Kilo Cloud sessions in the Agent Manager. Cloud workspaces for each project's repository appear as a Cloud location next to Local and worktrees, with their root sessions, and open in the ordinary chat to read history, send prompts and commands, answer questions and permissions, and stop a turn. Opening a Cloud session never wakes its compute, and closing a tab or the panel never stops remote work.
